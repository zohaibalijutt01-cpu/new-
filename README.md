# Zohaib — AI Chatbot Portfolio

A single-page portfolio website for an AI chatbot developer, with a live demo chatbot built in.

## Files
- `index.html` — the whole site (HTML + CSS + JavaScript in one file)

## Placeholders
Search `index.html` for `[brackets]` to find everything to replace:
your full name, tagline, email, WhatsApp number, prices, stats, client reviews, and photo.

## Deploy
- **Vercel:** import this repo in Vercel — no build step needed, it deploys `index.html` as a static site.
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` → `/ (root)`.
